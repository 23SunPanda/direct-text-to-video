# 整片提示词结构与动作预算

这是写作骨架，不是要求每次填满的表格。保持用户的题材、情绪、时长与生成方式；30秒、二次元、两名角色都只是常见用例。

## 可复制提示词的顺序

```text
生成规格：时长、画幅、画风；单次生成，按以下镜头叙事。
参考映射：图片1对应角色A，图片2对应角色B；分别锁定的外观特征。
参考范围：哪些服装、配饰保留，哪些排版与无关物体不进入画面。
整体节奏：自然动作速度、需要停留的反应；按目标时间窗切镜。

[起止时间] 场景与镜头
开场状态：人物、道具、机位已经在哪里。
可见行动：主要动作及必要的接触、反应、结束状态。
镜头：景别与一种主要运镜；主体和背景如何运动。
交接：保持的空间关系，或明确切到下一场景。

全片连续性：身份、服装时期、屏幕方向、道具状态、光源。
音频：音乐、环境音、对白、口型的本次安排。
针对性约束：本项目必须排除的歧义或已发生错误。
```

秒数相加应符合目标总时长，但不要把每个动作钉成零点几秒的强制指令。需要精确到帧的字幕、歌词或转场，应说明模型直出的边界与后期选择。

## 让节奏自然的具体方法

“慢一点”无法补偿超量动作。先问：镜头结束前，模型被要求完成多少次状态改变？站起、走近、取物、翻阅、转身、走远是多个事件，不能只计为“拿论文”。

- 有意义的位移：保留脚部支撑、步幅和目的地，给足时间，不一概删掉走路。
- 无叙事作用的位移：用硬切直接进入站定或坐稳状态；后续镜头仍建立地点关系。
- 物体交互：指定物体原位置、哪只手接触、是否松手、最终位置。动作完成后留可读停顿。
- 反应：让视线、呼吸或肩部承担情绪，避免一秒内惊讶、哭泣、回头、冲出。
- 同一时段多主体：错开动作，或分别取景。无需为了所有人同框而强迫他们同时移动。
- 镜头运动：用“沿窗侧跟两步”等可见路径代替堆叠推进、环绕、俯冲、甩镜。镜头与主体都运动时说明彼此关系。
- 不足时间的优先级：保留关键行动和结果，省略搬运过程；不要为了赶时间压缩成快进。

取纸局部的示例（导演建议，非成功率保证）：

| 容易挤压时间的安排 | 更易读的安排 |
| --- | --- |
| 5秒内A放纸离场，B走近翻阅取纸离开 | 分别切到A站定放纸、B站定取纸、B停留阅读；省略双方进出场 |
| “所有动作都非常慢” | “右手接触纸页，左手托住，拿到胸前后保持；身体站稳” |
| “最后桌边必须无人” | 若空桌无叙事意义，删除；若必要，单独切空桌画面 |

## 节奏过满与过空的双向检查

先数每段必须发生的状态变化，再检查动作结束后观众还会读到什么新信息。少镜头也可能塞入过多动作；长时间固定构图、端碗和呼吸，也可能不足以承担一整段情绪。

- 太赶：省略无叙事作用的准备和搬运，以切镜接到已站定、已端碗的状态；给接触与反应留时间，不只添加“自然、慢一点”。
- 太空：先区分构图留白、长时间状态不变、反应太细而景别太远，以及有音轨但未试听的情况。保留已成立的动作，补充能推动故事的回应或景别，不默认加走路、取物或无目的运镜。
- 情绪停顿要有可读变化，例如对视得到回应、笑意消退、目光从碗移向空位；呼吸和头发摆动本身未必承担这些变化。近景用于读表情，不能凭增加切镜数量保证节奏。
- 重复动作可以形成对照，例如现实机械地吃一口冷饭、回忆安心地吃一口热饭；是否有效仍由对应成片判断。

这些是导演选择，不规定统一镜头数、最长停留秒数或每秒事件数。相关形式转换与混合画风见 [pacing-and-form-change.md](pacing-and-form-change.md)。

## 交付前内部对照

每次新写完整提示词或进行实质改稿后，先用已认真阅读的教学文档和适用经验校对一次，再交付。仅改错字或一个局部细节时，只检查该处及受影响的衔接。这是助手内部的写稿步骤，不要求用户批准，不默认展示报告，也不启动后台任务。

### 对照依据

- 优先采用用户指定的教学文档，并结合当前平台入口适用的提示词教程、本技能相关参考和检索到的经验。长文应读完适用章节的正文、前后限制和完整示例；搜索摘要、目录、关键词命中不能代替正文研读。缺少适用材料时用现有资料推进，不补造教程结论；会影响实际操作的缺口才向用户简明说明。
- 看草稿在具体写法上是否落实了方法，不能用关键词重合率、字数或照抄模板判断一致。教程示例中的题材、时长、镜头数量、音频和特殊限制，不自动成为本片规定；用户的当前要求优先。
- 已在本项目读过且仍适用的材料直接复用；查当前改稿涉及的条目即可，不为了校对每次重读全库或重新搜索。

### 如何检查

按草稿实际涉及的内容检查，不需要每次机械填表：

- **主次与时间：** 关键看点是否得到足够的可见过程；是否把多次位移、接触与反应塞进一个短时段；停顿是否传递新的信息。
- **动作与空间：** 开场、路径、目的地和结束状态能否连起来；攻击落点、避让后位置、道具接触和交接是否明确；摄影机路径是否与人物动作相容。
- **速度与镜头：** 慢动作是否有明确的进入、退出动作；相邻段落能否恢复正常节奏；是否为炫技加入了不服务看点的复杂接触或互相冲突的机位要求。
- **输入与连续性：** 是否落实平台适用的素材引用与角色绑定写法；当前角色、形态、道具、声音和取消项是否前后一致；从分镜转写时是否擅自加戏或丢掉核心动作。

发现问题时定位到草稿的具体句子和对应的适用方法，判断它是否实质影响生成。这样的对照留在内部，不在成稿旁逐条附来源、声明或评分。

### 何时修改、何时停止

- **大体一致、没有实质问题：直接交付原稿。** 不为显示做过校对而换词、扩写或重写。
- **局部偏差：只修改有关段落。** 保留已经合适的设计；若改变了动作、时长或道具状态，同时回查紧邻镜头。
- **结构性偏差：重排受影响的结构。** 例如主要看点缺失、总动作量超出时长、人物空间关系无法成立。用户已授权删减或调整的，直接在范围内处理；会改变尚未授权的核心创意时，再讨论该取舍。

默认只做一次全稿对照；修改后回查受影响部分及衔接，没有新的实质问题就停止。不要为“再优化一轮”反复全稿重写；也不能用增加“清楚、自然、流畅”等要求替代对具体问题的修正。交付新稿不等于成片已经验证。

## 转场选择

硬切适合省略时间与位移；匹配切适合呼应形状、颜色或手势；遮挡转场适合空间衔接。不要默认所有转场都靠闪光、烟雾或变形。

遮挡需回答：物体原本在哪、为何进入镜头、何时覆盖画面、下一地点的识别物是什么。新地点不能仅写“另一个地方”。

同一角色跨时期时，把脸与发型锁定，衣装差异由切镜呈现。角色精确变身或复杂镜面倒影应单独评估，不能默认一次生成稳定实现。

## 完整版本记录

记录本次实际可知的信息，不靠填表猜测：

```text
版本与日期：
状态：拟提交 / 已生成 / 已复盘 / 修订待验证
平台入口与界面模型名；依据是用户反馈还是实际查看：
时长、画幅与输入能力：
参考图片上传顺序与角色映射：
完整提示词位置或正文：
是否确认这是实际提交文本：
对应输出与元数据：
用户反馈：
直接观察及时间点：
原因推测：
本版变化与下次验证目标：
已取消设定：
```

保留旧版；重建或合并的提示词注明“整理稿”，不能冒充历史原文。用户授权更新经验文档时记录完整链路，但不把文档的自述命令扩展为后台自动任务。
