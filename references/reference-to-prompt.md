# 看参考视频，再反推整片提示词

用于从参考片学习叙事、表演、节奏或视觉方法，再用指定角色写类似短片。目标是得到能执行的新导演方案，不是猜中原片逐字提示词；成片本身不能证明模型、平台或一次生成方式。

## 先分清证据与理解

- 用现有工具读取时长、画幅、帧率与音轨，按 video-review.md 检查画面。具备播放和试听能力时实际观看与听取；否则明确本轮依赖了哪些证据，不把抽帧说成完整观看。
- 将实际可见的动作、实际听到的声音、工具转写、用户解释和导演推测分开。画面中伸手、交手机、低头，不足以独立证明“打劫”或“吃掉手机”。
- 如果声音承担动机、人物关系或反转，先核实关键对白。可用现有转写辅助；乱码先排除输出编码问题，与画面无关的常见字幕套话不作为剧情证据。转写不能确认完整语气、音效、音乐或口型同步。
- 无法核实的部分只标明具体缺口，不泛化成“看不懂视频”。仍可交付已确认的画面观察；需要时只追问影响改编的关键情节。用户已经解释过的动机直接沿用，注明来自用户，不反复索要证明。

## 从事件提炼用户要学的东西

先用一句话概括“角色想要什么，做了什么，对方如何回应，结尾改变了什么”，再判断吸引力来自哪里：

| 层面 | 关注内容 |
| --- | --- |
| 因果结构 | 索要、得手、升级、反转；前一个事件为何引出下一个 |
| 角色表演 | 装凶、偷笑、得意、愣住、委屈、嘴硬等可见反应 |
| 拍摄关系 | 谁是第一视角，谁看镜头，镜外人如何说话与介入 |
| 视觉呈现 | 人物、背景、道具各自的材质，机位、景别和特效 |

这些是分析维度，不要求每次全部照搬。用户说“学可爱点”时，优先找身份与姿态、意图与能力之间的反差，以及结尾仍暴露性格的反应。用户排除的元素及时删除。

例如，本次参考的叙事意图由用户说明为：猫咪打劫，抢到东西仍不收敛，最后被制裁。可迁移的是“小小一只却很嚣张 → 得手后得寸进尺 → 被轻松拿捏”的结构。喷火和火焰尾巴属于原片的外在手段，不是这个结构的必要条件。该例不意味着所有参考片都要写成打劫喜剧。

## 用新角色重建因果

实际查看用户指定的角色图，将身份特征和性格偏好用于行动设计，不把原片动作机械换脸。

- 区分角色已有设定和本次提出的创作选择。例如“爱吃大米饭”来自用户；“饭碗高的尺寸、用饭勺当武器”是本次改编选择，不能据此改写所有角色的永久设定。
- 角色图只上传一张时，可作为身份参考；三视图仍是一名角色。背景可用文字描述，不因原片采用实拍背景就强制要求用户另传场景图。
- 对“实拍背景＋二次元人物”，分别说明真实环境和人手的摄影质感、角色的描线与平涂阴影。用一致光向、接触阴影与实际接触关系把两者连接起来，不能把全片一并写成写实或3D。
- 第一人称也参与对白时，写清声音来自镜头后，人的身体是否出镜、哪只手进入、与角色和道具如何接触。不要只给角色台词。
- 结尾反应应延续人物欲望。例如被提起后还伸手够饭，比单纯惊叫更能体现贪吃；是否采用这种结尾取决于本次角色和故事。

## 先剧本，后提示词

用户只要求先看参考时，给出简洁理解和必要的不确定项，等待后续创作要求。用户先要规划时，给出覆盖总时长的动作、反应与对白安排；不要提前生成最终提示词或调用视频生成。

对约10秒短片，可采用少量连贯节拍：提出要求、满足要求、继续升级、反转及反应。它是可选结构，不是固定镜头数，也不必等分时长。开场可直接处于事件中，给关键表情和结尾留出时间。将对白念完所需时间计入动作预算，避免两人抢话或末段快进。

用户确认并索要提示词后，读取 prompt-pattern.md，交付上传映射和一份完整合并稿：

- 规格与风格分工、身份参考和参考范围。
- 开场机位、人物尺度、道具位置与归属。
- 每段的可见动作、情绪反应、说话者与原句、结束状态。
- 交互中的手、接触点、松手时机、物品最终位置，镜头如何保留反转所需信息。
- 当前项目的声音安排，以及针对已知歧义的少量约束。

已取消的内容不再进入正向动作。不要把分析解释、疑问或多个可选方案混入复制区，也不要只交付对旧稿的补丁。

## 交付边界

用户确认剧本，只说明创意方向获认可；没有新成片就标记提示词拟提交或待验证，不声称成功复刻。后续拿到生成视频，再检查笑点是否读得出来、动作与对白是否成立，而不只核对提示词中的元素有没有出现。
