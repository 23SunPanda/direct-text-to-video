## 2. 本次最值得保留的结论

1. **先画清空间关系，再写镜头路线。** 人物、入口、出口、柜台、汽车两侧和立柱必须先有确定位置。
2. **镜头路径要写经过什么，不能只写最终到哪里。** “穿过汽车”不足以限定驾驶侧进入、副驾侧离开。
3. **车辆前后与左右是两套独立约束。** 修好入口在哪一侧，不代表修好了车尾到前排的关系。
4. **撤离要用目的地和可见行动定义。** “转身离开”容易生成背对镜头后走向银行深处。
5. **人物介绍从动作中截取。** 发现镜头、飞吻、敬礼可以发生在任务行动里，不必先站好表演。
6. **姿势越复杂，越容易中断主动作。** 本次金发少女的内八、折腿、搭膝要求已取消，不能再写回新版。
7. **伪一镜到底依赖连续关系和遮挡。** 连续、可理解的空间比堆叠运镜名词更重要。
8. **转场道具必须先有位置、形状和运动。** 立柱不能凭空出现，报纸不能拉成长丝带。
9. **换地点要写出新地点的识别物。** “露出新场景”不足以让银行自动变成仓库。
10. **手绘风格必须覆盖车辆与背景。** 只约束人物，会生成二维少女配写实汽车和建筑。
11. **配乐要有主旋律、律动和编曲结构。** “复古爵士、萨克斯”不足以决定 OP 的冲劲。
12. **长提示词的价值在于解决歧义。** 新增一段，应补充空间、动作因果、衔接或状态，而不是重复形容词。

## 5. 动画 OP 的感觉从哪里来

本次主要风格参考是《永生之酒》的群像介绍，《无头骑士异闻录》的空间与角色交接，以及《星际牛仔》的图形节奏。这是供导演理解的参考，不必把作品名直接堆进模型提示词。

用户希望人物有性格、有表演。仅有摄影机移动、头发摆动和漂亮立绘，仍会像拍摄展示片。可以通过以下关系建立 OP 感：

- 人物正在执行任务，顺便与镜头互动。
- 强关键姿态与短暂停顿之后，立即接回动作。
- 人物、道具、摄影机的运动有先后和惯性。
- 大字、色块、小字与音乐重音形成不同节拍。
- 人物之间有交接，分赃时有相互回应。
- 片尾是有辨识度的最终画面，而不是普通淡出。

“紧迫感”不要求人物全程惊慌。金发少女可以优雅、傲气，蓝发少女可以冷静；任务仍通过快步、观察、明确出口和环境余波持续推进。不能为了强调紧张而删除用户明确希望的飞吻与敬礼。

## 6. 汽车镜头：先沿车长，再穿车宽

### 6.1 两个阶段分别定义

```text
阶段 A：驾驶侧车尾低处
→ 后轮 → 后门 → 前后窗之间的立柱 → 前门 → 后视镜
→ 到前门后才抬升到驾驶窗

阶段 B：驾驶侧窗进入
→ 驾驶员面前的空隙 → 中控台上方 → 空副驾座上方
→ 对侧副驾窗离开 → 银行入口
```

车头朝同一路口，车尾朝相反方向。左舵、驾驶员在前排左侧、空副驾在前排右侧、银行在副驾外侧。两扇前车门关闭，两侧前车窗完全打开。

### 6.2 本次出现的错误

- 驾驶员近景已经从副驾侧观看，副驾座比人物更靠近摄影机。
- 介绍后镜头拉远，空副驾座回到前景，再从同一侧退出。
- 车门被打开，用车门出口代替了车窗出口。
- 沿车身移动时，车头、车尾和车窗关系发生跳变，产生车尾抬升后直接接到驾驶座的观感。

因此，不能只检查“最后有没有出车”。还要检查入口、横穿过程、出口以及车身结构是否一致。

### 6.3 可复用描述

```text
摄影机先沿驾驶侧由车尾移到前门，经过后轮、后门、立柱、前门和后视镜，再向上抬升。驾驶员位于近处，空副驾位于车厢另一侧更远的位置。

介绍恢复后，摄影机继续向内横穿车厢。驾驶员从近景移出，中控台从下方掠过，空副驾座位于镜头下方，对侧打开的副驾窗逐渐占据画面。穿过窗框后，银行入口在眼前展开。
```

“不后退”只约束这段贯穿汽车的动作。进入大厅后，为伴随向外走的人物，可以后退跟拍。把局部约束写成全片禁止，会制造新的冲突。

### 7.2 “离开”不能代替路线

本次两位少女都出现过转身后走向柜台深处的情况。尤其蓝发少女敬礼时已经面对出口附近的镜头，再要求笼统“转身”容易把路线反转。

最新修正规则：

```text
蓝发少女完成向斜上方挑指，放下右手，保持面向入口，朝摄影机快步走来。柜台始终在她身后。她从摄影机侧旁经过，穿过破损门框到银行外，不做180度掉头。
```

这是目前确认的方向要求，尚无新成片证明已执行成功。

## 8. 金发少女：边走边飞吻

### 8.1 当前动作链

```text
已经在优雅快步撤离
→ 行进中注意到低处镜头
→ 转眼、轻侧头、微笑
→ 右手触唇并送出飞吻，同时继续迈步
→ 在行进关键姿态冻结介绍
→ 恢复后接着完成同一步，收手，继续向出口走
→ 左手傲气拎包，经过镜头出门
```

“优雅快走”要写成身体运动：步频较快、重心平稳、上身挺拔、肩膀放松，钱袋、衣摆和双马尾随步伐摆动。不能只写“优雅、丝滑”，也不能自动改成慢走、站定或跑步。

低机位用于这段人物展示。介绍期间保持原景别；恢复后摄影机停止跟随，可以升回正常高度，让人物自己经过并离开。

### 8.2 保留的拎包姿势

左手抓提手，左肘抬起，前臂向上，手腕向后翻折、手掌朝后，钱袋由左手悬提。气质傲气、自信。

不能写成钱袋提手挎在臂弯里。这个动作融入走路，不另停下来摆姿势。

### 8.3 曾经失败的沟通与过度拆解

旧方案曾要求内八、双膝降低、一条小腿以膝盖为轴折起、另一只手拿钱搭膝、单手飞吻。助手最初误写成高抬大腿；找到的蹦跳步和普通飞吻动图，也没有对应整套动作。

可复用的经验是：先确认抬的是大腿还是小腿、转轴在哪、脚朝哪里、支撑脚与道具手如何分工；没有找到完整参考，就明确说只对照了某一部分。

但本项目已经取消这套复杂腿部要求。不能为了“总结详细”重新把它放进当前动作。

## 9. 蓝发少女：两指敬礼与恢复动作

动作链：观察左侧 → 观察右侧 → 看向镜头 → 右手两指并拢抬到额角 → 原位冻结 → 恢复后向斜上方挑出 → 放手 → 朝出口撤离。

需要明确：

- 左手稳定支撑步枪，枪口朝侧下方；右手负责手势。
- 食指与中指伸直、紧贴并拢，其余三指收拢。
- 指尖抬向额角，避开眼睛，不停在脸颊旁。
- 冻结点是指尖刚到额角、尚未向上挑出时。
- 恢复后必须完成挑出动作，不能继续保持敬礼姿势然后直接换镜。
- 离开方向是破损入口，不是柜台深处。

成片出现过两指分开、形似 V 手势、指向眼睛附近和动作收尾缺失。手指文字约束可以帮助表达，但尚不能保证模型逐次稳定执行。

## 10. 本项目的“子弹时间”与动态介绍

这里的定义是：**人物和摄影机原位冻结，背景硬切成图形，文字与色块运动；恢复原背景后，动作继续。**

不是要求摄影机在冻结人物周围环绕，也不是要求冻结后换一个更漂亮的构图。

| 角色介绍 | 当前冻结点 | 图形设计建议 |

| GLM | 驾驶员转眼与镜头对视 | 钴蓝、亮青、黑；横向错动色条 |

## 11. 立柱、报纸与钞票三类遮挡

### 11.1 立柱：空间内的镜头交接

必须先在大厅远景中出现。金发少女出门后，摄影机向近处右侧立柱侧移，柱面从右侧进入，覆盖全画面，再从左侧退出，露出同一大厅原位置的蓝发少女。

检查覆盖期间是否真的看不到旧画面；退出后柜台与隔栏是否还能对应。只写“利用柱子转场”，容易得到立柱从边缘擦过或凭空闪现。

本次最后一支成片中确有短暂柱面遮挡，不能把它说成完全没有转场。问题是人物错误的撤离路线与遮挡前后的站位没有共同建立可理解的交接。

### 11.2 报纸：跨地点与时间的剪辑接口

从上方飘落，正面逐渐朝向镜头。大照片展示三位角色与劫案现场，照片是静止的纸面印刷图像。清楚展示短暂一拍后，整张报纸盖住镜头。

满屏遮挡时，明确切到稍后的旧仓库。报纸落下后先看见木桌、砖墙、钢梁、木箱与斜光，再看三人分赃。新地点不是纸面照片变成实景，也不是银行柜台后面突然出现一张桌子。

失败记录包括报纸变成长条或旋转丝带、照片不足以辨认三人、报纸停留太久，以及遮挡后仍沿用银行背景。

### 11.3 钞票：从故事动作到片尾图像

金发少女抛钞 → 摄影机随钞票抬起 → 钞票受重力落下并覆盖前景 → 单张一美元钞票正面贴镜。

贴镜后裁掉纸币大部分边缘，让华盛顿头像占画面大部分。成片出现过完整纸币展示、肖像占比不足，以及面额与肖像混乱，必须逐帧检查。

饱和度在贴住瞬间骤降，音乐重音结束，纸面轻颤并保持，不用普通淡出。

## 12. 银行破损与仓库：用识别物锁定场景状态

“现代银行”只定义建筑类型，不定义遭到破坏后的状态。“劫案”也不自动意味着门已被炸坏。

破损入口应写出缺失玻璃、扭曲金属门框、脱落构件、焦痕、地面碎片和仍在飘落的灰尘。保留可通行缺口。按当前方案，破坏已经发生，不追加一段爆炸过程占用片长。

“破旧仓库”也不能只靠名称。优先写新地点正向识别物：裸露砖墙、锈蚀钢梁、旧铁皮屋顶、木箱、托盘、粗木桌和高窗斜光。再补少量排除项：没有 ATM、银行柜台、叫号屏与排队隔栏。

分赃地点错误，一部分来自提示词未充分定义，一部分来自模型沿用上一场景。不能把所有问题都归为模型不听话，也不能承诺补一句名称就会修好。

## 13. 手绘锚定词：定义线、色、背景和运动

| 描述 | 要求出现的可见效果 |
| --- | --- |
| finished hand-drawn 2D Japanese cel animation | 完成上色的二维动画，不是草稿或故事板 |
| visible ink linework / variable line weight | 外轮廓有力度、内部线较细、粗细自然变化 |
| flat cel colours / hard-edged two-tone shadows | 鲜艳平涂与硬边阴影，减少立体渲染渐变 |
| graphic hair masses | 发束与块面明确，减少逐根模拟发丝的 CG 观感 |
| painted backgrounds | 建筑、地面、仓库有绘制笔触 |
| drawn mechanical details | 汽车、中控、步枪具有手绘结构线 |

少量手绘不规则感不等于轮廓每帧抖动。少量胶片颗粒不等于厚重 VHS 滤镜。速度线与拖影应服务快速动作，不能让整段人物持续模糊。

## 14. 音乐：把参考事实与创作尝试分开

### 14.1 已核实的参考事实

《永生之酒》官网将 Paradise Lunch 介绍为铜管摇滚组合，并描述《Gun’s & Roses》融合爵士、摇滚与灵魂乐元素。因此，不能把这首参考音乐简单定性为纯大乐队摇摆爵士。[官方 OP 介绍](https://www.baccano.jp/oped/)

### 14.2 两个不同方向，不应混为同一个结论

| 方向 | 依据与用途 | 当前状态 |
| --- | --- | --- |
| 铜管摇滚，融合爵士与灵魂乐 | 更接近官网对参考音乐的描述 | 已提出创作方案，用户未认可生成音乐 |

### 14.3 真正需要写出的音乐事件

- 第一秒进入鲜明动机，而不是长氛围铺垫。
- 简短、容易记住的两小节旋律反复并发展。
- 萨克斯短句与小号、长号回应，有明确主次。
- 低音与鼓组持续推进，不只给零散管乐音符。
- 人物背景硬切对应铜管重音，图形进入分配在后续节拍。
- 报纸转场有短鼓花，仓库段延续主旋律，钞票雨增强，贴镜整齐收尾。

168 BPM 是速度，不保证旋律、摇摆比例、乐器音色与编曲质量。原生配乐如果继续偏离，可考虑单独生成或选择音乐再配图，但这是可选生产路线，不是本次用户输入方式的强制要求。
