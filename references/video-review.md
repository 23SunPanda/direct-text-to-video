# 生成视频复盘

目的：把“很怪”“突然快”“不连贯”变成可定位的观察与可检验的修改。没有拿到视频时只能根据用户描述提出可能原因，不编造时间点。

## 按问题选择检查

1. 读元数据：分辨率、视频/容器时长、帧率、帧数、音轨。检查用户报告是否与实际文件一致。
2. 全片先连续观看（有播放能力时），再稀疏抽帧定位故事、场景与身份；约每秒一帧可作为30秒片的初筛。
3. 对异常段每0.1—0.25秒或逐帧检查，按需选择密度；抽帧不要一开始铺满全片。
4. 区分画面中的角色运动与镜头运动。背景稳定而人物大幅滑移，才支持主体滑移判断；移动镜头不能只看角色像素位移。
5. 用户报告突然变速时，检查帧时间戳，必要时检查播放器、剪辑和重复/漏帧。固定帧间隔只排除了该文件时间戳突然变速，不证明动作自然，也不能排除已经烘焙进画面的速度变化。
6. 有音轨不等于符合音频要求。没试听就写未试听；静态接触表无法验证完整节奏、口型与声音。
7. 对白可能决定剧情时，优先核实声音再下结论。无法直接试听时可用现有语音转写工具辅助，注明这是转写而非亲耳听到。输出“字幕by……”等与片中事件无关的文字，可能是识别幻觉，不能当作真实对白；没有可靠转写不等于原片没有对白。关键语句仍不明时，提出一个针对性问题，请用户补充该句或解释情节，同时继续可独立核实的画面检查。

## 可用的只读命令

使用系统现有ffprobe/ffmpeg；缺少时说明限制，或选择现有可用工具。不把安装依赖变为提示词任务的前提。

```powershell
ffprobe -v error -show_entries format=duration:stream=index,codec_type,codec_name,width,height,r_frame_rate,avg_frame_rate,nb_frames,duration -of json '输入视频.mp4'
ffprobe -v error -select_streams v:0 -show_entries frame=best_effort_timestamp_time -of csv=p=0 '输入视频.mp4'
```

抽取时使用单独输出目录，保留原文件，避免覆盖已有证据。以下时间仅为示例，替换为实际问题范围：

```powershell
ffmpeg -n -i '输入视频.mp4' -vf 'fps=1' '已创建的输出目录/overview_%03d.png'
ffmpeg -n -i '输入视频.mp4' -ss 13 -t 4 -vf 'fps=8' '已创建的输出目录/detail_%03d.png'
```

给图标注实际时间或原帧索引，尤其在二次抽样、可变帧率或seek后不要用图片序号冒充原视频帧号。用可用图像查看工具实际查看抽取结果；创建了图片不等于完成了审查。

## 从观察到修订

| 问题 | 先核实 | 可选修订方向 |
| --- | --- | --- |
| 拿完道具突然滑出画面 | 位移、脚步、背景、PTS、是否要求限时离场 | 省略离场，切到下一状态；必要位移增加预算 |
| 人物站很久随后快进 | 前段停留与后段动作数量 | 减少末段事件，把关键动作提前，明确完成后的停留 |
| 论文/遮挡物变形 | 变形前后帧、提示词是否把切换写成变身 | 改为匹配硬切，写清新场景 |
| 角色变化或道具复制 | 参考映射、切前后位置、双手物体数量 | 收紧身份与物体状态，简化同时交互 |
| 撤退反而走向室内 | 出口位置、面向、屏幕方向和机位是否变化 | 指定目的地和可见路径，重新建立空间 |
| 用户觉得“太空” | 构图留白、同一状态持续时间、景别能否读清表情；声音是否实际试听 | 缩短无新信息的停留，补有叙事作用的回应或近景，不恢复无关搬运 |
| 正常形态变Q版不成立 | 门内外、越过门槛的时点、何时已呈Q版、变身是否实际可见、环境尺度 | 分清入屋、关门与变身；按故事优先级省略开关门或落坐，单独给关键变化预算 |
| 混合画风被同化 | 写实对象与二维对象分别检查，核对本版是否已要求例外 | 按对象划分风格范围，移除覆盖例外的全片统一措辞，不宣称文字已保证实现 |

“动作过多造成时间挤压”是可用的导演假说，不能写成已证实的模型内部机制。放慢现片只延长现有帧，不能恢复缺失的自然步态。

对“太快”与“太空”的连续反馈保留两轮证据：减动作后得到反例，应收窄原建议，不能写成“越少动作越自然”。静态抽帧可以支持姿态变化少的观察，不能独自确认连续播放的节奏与音效。设计判断与形式转换的具体处理见 [pacing-and-form-change.md](pacing-and-form-change.md)。

## 复盘交付

先说主要问题与证据，再分开写原因推测和修改方案；给最小必要的截图链接，不用大量接触表淹没用户。用户索要新提示词时交付完整合并稿，版本状态保持“待验证”，直至对应新成片可检查。
